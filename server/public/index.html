Despliegue en Render & GitHub
1
Crear Repositorio en GitHub

Crea un repositorio en GitHub.com y sube la carpeta server.

2
Conectar a Render.com (Gratis)

En Render.com crea un nuevo Web Service y selecciona tu repositorio.

3
Pegar URL en el POS

Copia la URL que te da Render (ej: https://mi-caja.onrender.com) y pégala en el botón Nube de la caja.

El servidor incluye render.yaml para configuración 100% automática.
